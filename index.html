AWB

Agent = Model + Harness. AWB wraps your coding agent in pre-action hooks, scope and secret gates, architecture boundaries, and a ratchet that turns every failure into a permanent rule. Stack Packs ship opinionated checks for Spring Boot, Go, NestJS and React/Vite.

# install guardrails and a stack pack, then run
$ npx @awb/cli init --demo
$ awb hook install -t demo
$ awb pack install spring-boot
$ awb run add-order-endpoint --agent claude --max-cost 0.50

        Does AWB send my code anywhere?

        No. The CLI, gates and dashboard all run locally. There's no telemetry. Your agent talks to its own provider as usual.

        Which agents does it work with?

        Claude Code, Codex, Gemini CLI and Antigravity, plus any custom CLI you can call from a shell.

        Will it slow my agent down?

        Gates run your existing build, lint and test commands, so a check takes about as long as running them yourself. A failed check saves you finding the same problem in review.

        What's the difference between Core and Pro?

        Core gives you the harness, guardrail hooks and the generic, React and security packs. Pro adds the Spring Boot, Go, NestJS, Postgres, Docker, OpenAPI and monorepo packs, automatic ratchet learning and headless CI output.
